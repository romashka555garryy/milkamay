# NovaPulse Messenger

Полноценный локальный/серверный мессенджер с русским интерфейсом, AI-вкладкой, личными чатами, поиском собеседников, голосовыми сообщениями, темами и WebSocket-синхронизацией между пользователями.

## Установка
```bash
npm install
npm start
```

После запуска откройте `http://localhost:3000`.

## Что умеет
- регистрация и вход
- русский интерфейс
- поиск пользователей
- личные чаты в реальном времени через WebSocket
- AI-чат на русском языке
- голосовые сообщения
- редактирование профиля
- темы, звуки, настройки и кастомизация
- loader, который исчезает через 2 секунды

## Важно
Для сообщений между разными пользователями и IP нужен запущенный сервер. Один только HTML для этого не подходит.


## AI
